# Triplan

여행 조건을 입력하면 일자별 경로와 일정을 보여 주는 여행 플래너의 **화면 시안**입니다.
정적 HTML/CSS 로 만들었고, 뒤에 이어진 [TripLinker](https://github.com/ynkite) 의 전신입니다.

- 기간 2025.11 – 2026.03
- 개인 프로젝트
- 2025 인덕대학교 컴퓨터소프트웨어학과

## 화면

| 파일 | 화면 |
|---|---|
| `project/index.html` | 메인 |
| `project/plan.html` | 여행 조건 요약 |
| `project/simple.html` | 경로 요약 |
| `project/detail.html` | 상세 일정 |

## 구성

```
project/      화면 4종 (HTML · CSS)
projectimg/   화면에 쓰는 이미지
```

`project/index.html` 을 브라우저로 열면 바로 볼 수 있습니다.
